# MatTart

本机科学计算工作台。使用命令窗口和脚本完成矩阵计算、统计和二维、三维绘图，并读写部分 MAT 文件。

[查看 v1.0.0 发布说明](https://github.com/MerlinScarborough/MatTart/releases/tag/v1.0.0) · [下载 Windows 便携试用版](https://github.com/MerlinScarborough/MatTart/releases/download/v1.0.0/MatTart-1.0.0-trial-win64.zip)

## 开始使用

1. 在装有 Microsoft Edge WebView2 Runtime 的 Windows 10（2004 或更新）或 Windows 11（64 位）上，完整解压 ZIP。
2. 在解压目录打开 `MatTart.exe`。Python 运行环境已随包提供。

## 使用条款

软件按随包的试用版条款提供，具体内容见包内《开始使用》。第三方组件许可随包附带。MatTart 与 MathWorks 无隶属关系。
